# namuh PLUG 게이트웨이 오류코드 (IGW*)

> 출처: NH투자증권 PLUG 개발자 포털 오류코드 표 (2026-08-31 확인).
> 게이트웨이(IGW) 레벨 코드다. 업무 응답 코드(`rsp_cd`, 성공 `00000`/`00166`/`00221`/`13578`)와는 별개 체계다.
> `scripts/plug/spec/`의 OpenAPI 명세에는 이 표가 포함돼 있지 않아 별도 기록한다.

## 처리 정책 (코드 반영: `PlugErrorCodes`)

| 분류 | 코드 | 처리 |
|---|---|---|
| **토큰 무효/만료** | `IGW40043` `IGW40044` | **재발급 1회 후 재시도.** 재발급은 이 경우에만 |
| **유량 초과** | `IGW42901` `IGW42902` `IGW42903` | **재시도·재발급 금지.** 호출 간격을 늘린다. 쿼터 거절 메트릭 증가 |
| **모의 도메인 미지원** | `IGW40401`, `IGW40023` | Mock 폴백 + WARN. 두 코드가 같은 상황을 다르게 말한다 — 2026-09-03 시세 API 차단 때 실제로 온 건 `IGW40023` |
| **일시적 서버 오류** | `IGW50001` `IGW50007` `IGW50011` `IGW50012` `IGW50020` `IGW50025` | 백오프 후 재시도 가능 |
| **자격증명 오류** | `IGW40031` `IGW40032` `IGW40035` `IGW40037` `IGW40039` `IGW40051` `IGW40054` | 즉시 실패. 재시도 무의미 |
