# FRACTA 데모 영상 촬영 대본

> 목표 길이 **6~8분** · 기준 커밋 시점 검증 완료
> ★ 5개가 차별 포인트다. 시간이 모자라면 ★ 아닌 것을 먼저 버린다.

## 이 영상을 어디에 쓰는가

| 용도 | 어떻게 쓰이나 |
|---|---|
| **README 최상단 링크** | 채용 담당자·면접관이 코드를 읽기 전에 3분 안에 "이게 뭐 하는 물건인지" 판단한다. FSD §16이 README 필수 항목으로 못박은 이유다 |
| **이력서·포트폴리오 링크** | 서류 단계에서 열어보는 사람은 저장소를 clone하지 않는다. 영상이 유일한 접점이다 |
| **면접 중 화면 공유** | "이 부분 보여주실 수 있나요"에 즉시 답할 수 있다. 라이브 시연은 사고가 나지만 영상은 안 난다 |
| **기술 블로그·발표 자료** | ★ 구간만 잘라 쓰면 그대로 클립이 된다 |

**보는 사람은 기능 목록이 궁금한 게 아니다.** 조각투자 앱은 화면만 보면 어디나 비슷하다.
차별점은 **"금융 시스템이 지켜야 하는 것을 어떻게 지켰는가"** 이고, 그게 ★ 5개다.
각 ★에서 한 문장씩 **왜 이렇게 만들었는지**를 말하는 게 이 영상의 전부다.

## 촬영 전 준비 (5분)

**PowerShell** (Windows 기본 · 이 프로젝트의 개발 환경)

```powershell
# 1) 완전히 깨끗한 상태에서 시작한다
docker compose down -v

# PowerShell에는 `VAR=x 명령` 문법이 없다. $env: 로 먼저 넣는다.
$env:BATCH_SCHEDULING_ENABLED = "true"
$env:BATCH_RECONCILIATION_CRON = "0/20 * * * * *"
docker compose up -d

# 2) 백엔드가 뜰 때까지 기다린다 (healthcheck 통과 후 프론트가 시작된다)
do { Start-Sleep 3 } until (
  (try { (Invoke-RestMethod http://localhost:8080/actuator/health).status } catch { $null }) -eq "UP")
"백엔드 준비 완료"

# 3) 데모 데이터 (약 1분)
node scripts/seed/demo-data.mjs
```

<details><summary>bash / zsh 를 쓴다면</summary>

```bash
docker compose down -v
BATCH_SCHEDULING_ENABLED=true BATCH_RECONCILIATION_CRON="0/20 * * * * *" docker compose up -d
until curl -sf http://localhost:8080/actuator/health > /dev/null; do sleep 3; done
node scripts/seed/demo-data.mjs
```

</details>

> **촬영이 끝나면 환경변수를 되돌린다.** `$env:` 로 넣은 값은 그 터미널 세션에 남는다.
> 새 터미널을 열거나 `Remove-Item Env:BATCH_SCHEDULING_ENABLED, Env:BATCH_RECONCILIATION_CRON`.

**배치 주기를 20초로 줄여 띄우는 이유** — 대사 배치는 원래 매일 23시다. 영상에서 기다릴 수 없다.

**확인할 것**
- 시드 출력 마지막에 상장 3종목 + 청약 1종목이 찍힌다. **토큰 심볼은 매 실행마다 바뀐다** — 대본의 `FR-XXXX-001`은 그때 값으로 읽는다
- 브라우저 탭 3개를 미리 열어둔다: `localhost:3000`, `localhost:3001`, 터미널
- 화면 배율 100%, 다크모드는 **라이트로 시작**해서 중간에 한 번 토글한다

## 컷 2 · 투자자 홈과 괴리율 배지 (0:40 ~ 1:40)

**화면** `localhost:3000` → `demo@fracta.demo` / `demo-password-1!`

1. 로그인 (자동 채워져 있다)
2. 홈에서 **상장 종목 카드 3개의 괴리율 배지**를 가리킨다

**말할 것**
> "괴리율은 조각 체결가가 기초자산 시세에서 얼마나 벗어났는지입니다.
> 1억짜리 건물의 100분의 1 조각이 12,600원에 거래되면 그 건물을 1억 2,600만으로 평가하고 사는 셈이죠.
> 조각투자는 유동성이 얕아서 주문 몇 건으로 이렇게 벌어집니다.
> 그래서 ±10% 초과는 경고, ±20% 초과는 **자동 거래 중단**입니다."

세 배지가 회색 / 주황 / 빨강으로 갈리는 것을 보여준다.
(시드가 만든 값: 정상 약 +2%, 경고 약 +16%, 중단 약 +27%)

## 컷 3 · ★ 자동 거래 중단 (1:40 ~ 2:30)

**화면** 빨강 배지 종목(제주 리조트) 카드 클릭 → 종목 상세

**보여줄 것**
- 헤더에 `괴리율 +27.xx% 거래 중단` 배지 + `주문 불가` 배지
- 주문 폼 상단의 빨간 안내
- **주문 버튼이 비활성**

**말할 것**
> "이건 화면에서 막은 게 아닙니다. 체결가가 임계치를 넘는 순간 서버가 종목을 SUSPENDED로 바꾸고,
> 그 이벤트를 받아 **미체결 주문을 전량 취소**합니다. 그래야 잠긴 수량이 영구히 묶이지 않습니다.
> 화면은 서버 상태를 따라 그릴 뿐입니다."

그다음 **정상 종목**(한남동)으로 이동해 기초자산 시세 차트와 호가창을 보여준다.
- **기초자산 시세 차트** — 캔들이 상승 적색 / 하락 청색 (국내 관행)
- 매도(청색) 위 / 매수(적색) 아래 — **국내 HTS 관행**
- 호가를 클릭하면 주문 폼 가격이 자동으로 채워지는 것

**차트에서 한마디 덧붙일 것**
> "차트 값은 원자산 가격이 아니라 **조각 참조가로 환산해서 서버가 내려준** 값입니다.
> 화면에서 분할비율로 나누게 하면 반올림이 서버와 갈려서, 차트와 호가창의 기준선이 어긋납니다.
> 그래서 이 프로젝트는 프론트에서 금액을 다시 계산하지 않습니다."

**화면** 로그아웃 → `conservative@fracta.demo` / `demo-password-1!` 로 재로그인

> **서버가 검색한 청크의 페이지 번호**입니다. 그래서 클릭하면 정확히 그 페이지로 갑니다."

> LLM 응답을 받은 **뒤에 코드로 검사**해서 차단합니다. 차단 사유도 화면에 그대로 보여줍니다 —
> 조용히 삼키면 사용자는 AI가 고장난 줄 압니다."

## 컷 7 · ★ 원장 훼손 → 대사 배치 검출 (5:30 ~ 6:30)

**화면** 터미널

```bash
node scripts/demo/tamper-and-detect.mjs
```

**보여줄 것** (약 15초면 검출된다)
- 대상 잔고를 **직접 UPDATE로 훼손**
- 배치가 `INV-1` 위반 검출 — **기대 2500 / 실제 4498 / 차이 1998**
- 종목이 `LISTED → SUSPENDED`

**말할 것**
> "블록체인 노드 없이 위변조를 잡습니다. 원장은 append-only 해시체인이고,
> 배치가 불변식 6종을 대사합니다.
> 중요한 건 **자동 복구를 하지 않는다**는 겁니다. 자동으로 맞추면 훼손을 덮어쓰는 거니까요.
> 검출 → 거래 중단 → 수동 조사가 원칙입니다."

훼손된 상태이므로 **여기서 촬영을 끝내거나**, 이어서 찍으려면 다시 `down -v` → 시드부터 한다.

## 촬영 팁

- **★ 구간에서는 말이 화면보다 앞서야 한다.** 클릭하고 나서 설명하면 늘어진다
- AI 차단 질문은 **25~30초** 걸린다. "이건 LLM 호출하고 출력까지 검사해서 좀 걸립니다"라고 미리 깔아둔다
- 실패하면 그 컷만 다시 찍는다. 처음부터 다시 갈 필요 없다
- 마우스를 천천히 움직인다. 배지·버튼을 가리킬 때 **1초 정지**
- 터미널 글자 크기를 키운다 (16pt 이상)

## 찍지 않는 것

| 항목 | 이유 |
|---|---|
| 관리자 발행 승인 화면 | UI가 없다. API 전용이고 시드가 대신한다 |
| 웹훅 수신 | 외부 수신 엔드포인트가 필요해 화면이 산만해진다 |
| 폐쇄망(Ollama) 전환 | RTX 4080 환경에서 별도 촬영. 실측 전에는 찍지 않는다 |
